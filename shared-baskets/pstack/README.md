# pstack

The principles from [pstack](https://github.com/cursor/plugins/tree/main/pstack) by
Lauren Tan (MIT), as chickens. Each file links back to the principle skill it comes from, and
its Origin quotes that skill's description verbatim.

This is an import, not a basket the author contributed. The pstack skills themselves
(`poteto-mode`, `architect`, `interrogate`, …) aren't copied here. Install the plugin for those.

Watch out: [`never-block-on-the-human`](chickens/never-block-on-the-human.md) conflicts
with gstack's [`user-sovereignty`](../gstack/chickens/user-sovereignty.md). Borrow one, not both.
