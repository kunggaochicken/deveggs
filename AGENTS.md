# deveggs: agent instructions

This repo is a developer's **basket**: harness-agnostic agentic-dev preferences
(`my-basket/`, gitignored) plus the shared baskets (`shared-baskets/`), the tooling that tends it (`src/`, `bin/deveggs`) and the
meta-skill that teaches any agent to use it (`skills/deveggs/SKILL.md`).

## Working on the tooling

- TypeScript, strict. Node >= 22.18 runs `src/*.ts` directly (type stripping), so
  use erasable syntax only: no `enum`, `namespace`, or constructor parameter properties.
  Import local files with the `.ts` extension.
- No runtime dependencies. Dev dependencies: `typescript` and `@types/node`.
- Run `npm run check` (`tsc --noEmit` + `node --test`) before committing.
- Model changes go in `src/basket.ts`. Harness wiring goes in `src/install.ts`. Add
  a new harness by adding an entry to `harnesses()`.

## Personal basket vs shared baskets

- `my-basket/` is the developer's **personal** basket. It's gitignored, except for
  `.gitkeep` scaffolding. **Never commit its contents to this repo**, and never
  `git add -f` it. Anything committed there would be pulled into everyone's basket.
  CI on `kunggaochicken/deveggs` rejects it.
- `shared-baskets/<github-username>/` is the **repository of baskets** that people
  chose to share, contributed by PR (see `shared-baskets/README.md`). Before opening
  one, warn the developer to review the Origin and `context` rows for anything
  private.
- A developer who wants their personal basket synced can fork, remove the
  `my-basket` lines from `.gitignore` in the fork, and commit it there. PRs to this
  repo must come from a branch without those commits.

## Working on the basket

- Follow `skills/deveggs/SKILL.md`.
- Items are `my-basket/{eggs,chickens,cracked}/<id>.md`. The folder is the tier (🥚 trial,
  🐔 permanent, 💥 rejected), the frontmatter holds kind, tags and trial counts, and
  the first body line is the fact.
- Skills are `my-basket/skills/{eggs,chickens}/<id>/SKILL.md` and move on hatch.
- `my-basket/PREFERENCES.md` is generated by `deveggs render`. Never hand-edit it.
